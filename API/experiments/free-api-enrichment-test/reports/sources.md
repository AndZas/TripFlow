# Официальные источники и решение о безопасном запуске

Проверено 27.10.2026. Опубликованный тариф не доказывает настройки личного кабинета; перед новым запуском сверить условия и остаток квоты.

| Кандидат | Официальная документация | Условия и решение |
|---|---|---|
| DATAtourisme | [API v1](https://api.datatourisme.fr/v1/docs?lang=en), [FAQ](https://www.datatourisme.fr/faq/), [ключ и лицензия](https://www.datatourisme.fr/utiliser-les-donnees/) | Бесплатный ключ по заявке; 1000 запросов/час, ~10/с длительно. Эксперимент до 9 последовательных запросов. Франция. Данные под Licence Ouverte 2.0: сохранять `hasBeenCreatedBy` и `lastUpdate`, указывать авторство и дату обновления. Права на конкретное фото проверять отдельно. В live разрешён. |
| Amadeus Self-Service | [Текущий портал](https://developers.amadeus.com/toolbox), [архивированная официальная документация](https://github.com/amadeus4dev/developer-guides) | Self-Service закрыт 17.07.2026; портал теперь Enterprise. Историческая документация о бесплатной Test квоте устарела. Новый ключ для этого эксперимента получить нельзя; `skipped_provider_unavailable`, live вызовы блокированы. |
| Wikidata + Commons | [Доступ](https://www.wikidata.org/wiki/Wikidata:Data_access), [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo), [правила API](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_API_Usage_Guidelines), [User-Agent](https://foundation.wikimedia.org/wiki/Policy:Wikimedia_Foundation_User-Agent_Policy/en), [права фото](https://foundation.wikimedia.org/wiki/Legal:Wikimedia_Developer_App_Guidelines) | Публичные GET без ключа; настоящий контакт в User-Agent. Один малый фиксированный парижский набор. Лицензия каждого Commons-файла и условия атрибуции индивидуальны. В live разрешён. |
| Foursquare Places | [Изменение цен](https://docs.foursquare.com/developer/reference/upcoming-changes), [фото](https://docs.foursquare.com/fsq-developers-places/reference/place-photos) | Pay-as-you-go: первые 500 Pro calls бесплатно, затем тарификация; фото и часть сведений относятся к отдельным категориям доступа. Жёсткий бесплатный sandbox без риска оплаты не подтверждён. `skipped_cost_not_verified`; live вызовов нет. |
| Booking.com Demand | [Требования](https://developers.booking.com/demand/docs/getting-started/prerequisites), [sandbox](https://developers.booking.com/demand/docs/getting-started/try-out-the-api) | Требуется Managed Affiliate Partner, договор, Partner Centre, token и affiliate ID даже для sandbox. Публичный свободный тест без партнёрства не подтверждён. Документальная оценка. |
| Expedia Rapid | [Getting started](https://developers.expediagroup.com/docs/products/rapid/setup/getting-started) | Требуется заявка и одобрение партнёрства; затем выдаются ключ и shared secret. Публичный бесплатный доступ не подтверждён. Документальная оценка. |
| Google Places | [Usage and billing](https://developers.google.com/maps/documentation/places/web-service/usage-and-billing) | Требуется включённый billing account, pay-as-you-go. Исключён без вызовов. |
| Ostrovok, Viator, GetYourGuide, Tiqets | Условия доступа не установлены достаточным официальным свидетельством для гарантированно бесплатного публичного live теста | `not tested`/`skipped_cost_not_verified`; не требовать ключи, не делать вызовы и не представлять их как закрывшие пробел. |

Ни один документальный кандидат без live результата не включается в измеренную заполненность. Лицензия данных DATAtourisme не превращает автоматически каждое вложенное фото в свободное изображение.
