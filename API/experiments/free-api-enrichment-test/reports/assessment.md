## Одинаковая городская выборка DATAtourisme

По 5 первых результатов для музеев, культурных мест и гостиниц в Париже, Лионе и Бордо: 45 записей (по 15 в каждой категории). Это малая выборка первого листа, не оценка Франции в целом. Категории могут перекрываться: музей Лиона появился и как музей, и как культурное место. Числа ниже относятся к записям, не уникальным объектам.

Во всех 45 записях были название, координаты, дата обновления объекта и имя производителя для атрибуции. Отдельно есть timestamp обновления каталога; это не дата тарифа. **Дата обновления конкретного тарифа не получена (0/10 записей с ценой).** Отдельный фильтр `hasMainRepresentation[exists]=true` для музеев в радиусе 5 км от центра Парижа дал 0 кандидатов — это не доказательство отсутствия фото во всей базе. Точечный фильтр по наличию `minPrice` нашёл 5 музейных и 4 гостиничных записи, **все 9 первых тарифов имели истёкший срок**; их нельзя использовать как текущую цену. Эти фильтрованные записи не входят в знаменатель 45.

В одном точечном ответе для Bourse de Commerce был минимум 15 EUR с периодом 2026-01-01–2026-12-31, но это `minPrice` без подтверждённой единицы и без доказательства, что сумма — именно обычный входной билет. У гостиниц встречались, например, 109 EUR и 21 EUR на 2026 год; без признака «за ночь/номер/человека», гостевого состава, налогов и наличия на даты их нельзя превращать в стоимость поездки или RUB/чел/ночь. Нулевое значение `admission_price_amount` здесь означает **неподтверждённую семантику**, а не отсутствие любых тарифов.

## Сопоставление и фотографии

Сохранённая база для сопоставления — 6 Geoapify POI из старого исследования, все в Париже. Точечный поиск DATAtourisme вернул по два близких объекта Musée Curie и Bourse de Commerce (у второго названия дополнены «Pinault Collection»). Совпадения помечены `ambiguous` либо `possible`, поэтому **0 уверенных межпровайдерных присоединений** в этом запуске. Эти дубли показывают, что имя и координаты недостаточны для автоматического прикрепления описания или тарифа.

Wikidata/Commons: из 3 заранее выбранных QID уверенно сопоставлены 2; у обоих есть описание и файл Commons с прямым URL, автором, страницей и лицензией CC BY-SA 4.0 / 3.0. Третий QID дал другое имя и исключён. Это поддерживает `optional` обогащение только при точном match и показе автора, лицензии и ссылки; 2/3 — результат выбранной подвыборки, не глобальный coverage. DATAtourisme в городском срезе фото не дал.

## Решения по полям

| Недостающие данные | Лучший бесплатный API по тесту | География/покрытие | Условие доступа | Решение |
|---|---|---|---|---|
| Название, координаты, описание | DATAtourisme | Франция, 45/45 городских записей с описанием | Бесплатный ключ, атрибуция автора данных и даты | `use` как дополнительный французский каталог, с проверкой качества текста |
| Фото отдельных POI | Wikimedia Commons | 2/3 выбранных QID, но 0/45 фото DATAtourisme | Публично, User-Agent с контактом, лицензия файла | `optional` после надёжного match и атрибуции |
| Обычный входной билет | Не подтверждён | Есть `minPrice`, но нет надёжной единицы/типа тарифа; часть данных устарела | DATAtourisme бесплатен | `reject` для автоматического бюджета на текущих данных |
| Ориентир гостиничной цены | DATAtourisme как исследовательский сигнал | 6/15 гостиничных записей с числом, 3/6 истекли, 0/6 с известной единицей | Бесплатный ключ | `optional` только как ненормализованный исторический минимум; для бюджета `reject` |
| Цена и наличие жилья на даты | Нет подтверждённого бесплатного API | Не получены | Amadeus Self-Service закрыт; Booking/Expedia требуют партнёрства | `not tested`/открытый пробел |

Не установлены точная стоимость билета, текущая цена номера на выбранные даты, налоговая база, состав гостей, наличие и надёжное глобальное покрытие фото. Foursquare и Google Places не вызывались из-за риска оплаты; Booking и Expedia требуют партнёрского доступа. Прежние результаты не изменялись.
