# Официальные источники и условия

Проверка документации: **26.10.2026**. Это проверка опубликованных условий и схем, а не подтверждение настроек личных кабинетов или живой выдачи API. Перед каждым живым прогоном нужно снова сверить статус плана.

| Источник | Документация и доступ | Условия и атрибуция |
|---|---|---|
| Geoapify Geocoding | [Forward Geocoding](https://apidocs.geoapify.com/docs/geocoding/forward-geocoding/), [Free pricing](https://www.geoapify.com/pricing/), [MyProjects](https://myprojects.geoapify.com/) | Free: 3 000 кредитов/день, 5 запросов/с, без карты; коммерческое использование Free допускается в рамках лимитов с атрибуцией Geoapify и источников данных. Endpoint `v1/geocode/search`, `type=city`, `filter=countrycode:us`, `bias=countrycode:none`, `format=json`. В ответе документированы `timezone`, `place_id`, `result_type`; валюта не обещана. |
| OpenTripMap | [Продукт](https://dev.opentripmap.org/product), [документация](https://dev.opentripmap.org/docs), [каталог видов](https://dev.opentripmap.org/catalog), [каталог JSON](https://dev.opentripmap.org/en/catalog.tree.json), [Free pricing](https://dev.opentripmap.org/price), [регистрация](https://dev.opentripmap.org/register) | Free: $0/мес., **только некоммерчески**, 5 000 запросов/день, 10 запросов/с. Данные ODbL и требуют атрибуции; для фотографий права проверяются отдельно. Интерактивная схема и JSON-каталог не открылись в текстовом просмотре 26.10; live CLI сначала валидирует JSON-каталог, а при недоступности пропускает POI. |
| Frankfurter | [v2 и FAQ](https://frankfurter.dev/) | Публичный бесплатный API без ключа, дневные справочные курсы. Документирован `v2/rate/{base}/{quote}`. Официальная страница указывает обновление раз в день; это не курс оплаты конкретной покупки. |
| Wikidata / Commons | [Wikidata Data access](https://www.wikidata.org/wiki/Wikidata:Data_access), [Wikibase Action API](https://www.mediawiki.org/wiki/Wikibase/API), [Commons machine-readable data](https://commons.wikimedia.org/wiki/Help:Machine-readable_data), [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo), [лимиты Wikimedia](https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits) | Публичное чтение без ключа. Для User-Agent с контактами 2026 документирует 200 запросов/мин, но лимиты могут меняться; при 429 уважать `Retry-After`. CLI не повторяет запрос автоматически, до 10 последовательных запросов. Commons `extmetadata` может содержать HTML и частично отсутствовать; URL изображения не является разрешением на показ. |

Кандидатные параметры OpenTripMap radius/details также отражены в прежнем [черновике контрактов](../../data-source-survey/reports/api-contracts.md), но там прямо указано, что рабочий ключ и интерактивная схема не проверены. CLI не предполагает их подтверждёнными, пока не получит официальный каталог и живой ответ.
