# Итог эксперимента: источники цен проживания

**Завершён 28.10.2026 по решению владельца проекта.** Ни один рассмотренный кандидат не выбран для текущего MVP. Причина завершения — несоответствие доступных вариантов ограничениям бесплатного студенческого проекта. Получение новых ключей и оставшиеся живые проверки прекращены. Решение о другом способе оценки проживания отложено; новая продуктовая схема этим экспериментом не утверждается.

## Что действительно проверено

- Прочитана официальная документация источников, исследованы условия доступа и опубликованные тарифы; ссылки сохранены в [sources.md](sources.md).
- Владелец самостоятельно зарегистрировался в Makcorps и сообщил об остатке **15 из 15 credits**. Это сообщение владельца, не результат вызова Account API. Постоянная возобновляемая бесплатная квота не подтверждена.
- Владелец сообщил, что форма Skyscanner не принимает его Gmail/Яндекс и требует website URL, которого у прототипа пока нет. Заявка не подана, доступ не одобрен. Официальная партнёрская страница ориентирует доступ на действующий бизнес с большой аудиторией.
- Найдены 8 сохранённых гостиничных образцов Geoapify по четырём городам; у 7 есть название, у всех — ID и координаты. Повторных запросов Geoapify не было.
- Реализован изолированный CLI. **28 локальных тестов прошли**, включая подставные цепочки Makcorps и Skyscanner, контроль credits, matching, нормализацию и защиту секретов. Проверены offline-отчёт и live с выключенными источниками: **0 HTTP-запросов**.

Живые ценовые запросы Makcorps, Skyscanner и Dataestur **не выполнялись**. Последнего валидного live-run цен нет. Подставные ответы тестов и пропущенные запуски не являются измерениями качества поставщиков. По этим кандидатам неизвестны доля пригодных цен, точность hotel match, свежесть, реальное покрытие и успешность RUB-нормализации; знаменатель равен 0, проценты не вычисляются.

DATAtourisme не проверялся повторно: прошлый эксперимент уже показал недостаточную семантику тарифов для автоматического бюджета.

## Ответы на исходное задание

1. **Цена конкретного отеля:** пригодный бесплатный источник этим экспериментом не установлен. Это не доказательство отсутствия таких источников вообще.
2. **Оценка по городу:** Skyscanner подходит документально по типу данных, но недоступен проекту на приемлемых подтверждённых условиях. Готового выбранного city-level источника нет.
3. **Единица суммы:** единый период цены не утверждён. При будущем исследовании нужны исходная валюта, `per_night`/`per_stay`, `per_room`/`per_person`, диапазон дат и дата источника. Неизвестные величины остаются `null`; цена не делится на число путешественников.
4. **Лейбл фронтенду:** если позже появится city-level оценка, показывать её отдельно как «Ориентировочные расходы на проживание в городе». Это рекомендация для будущего обсуждения, не изменение контракта.
5. **Ключи:** для закрытого эксперимента добавлять переменные среды не требуется. Названия и инструкции оставлены в README только для возможного возобновления.
6. **MVP:** эти источники не подключать. Автоматически заполнять стоимость проживания/`amountRub` по результатам эксперимента нечем; неизвестные значения остаются `null`. Выбор альтернативы будет обсуждаться отдельно.

## Закрытие программы тестирования

Исследование завершено отрицательным решением по доступу и пригодности кандидатов. Полная программа live из TASK не выполнена и не выдаётся за выполненную. Не получены числовые доказательства качества цен или глобального покрытия, не подтверждены расходы credits через API. Решение владельца прекращает оставшиеся live-сценарии, а не превращает их в успешные тесты.

В репозитории сохраняются исходное задание с отметкой о закрытии, CLI и защитные ограничения, конфигурационные примеры без секретов, тесты и итоговые документы. Локальные runs/config/секреты игнорируются Git. Платных вызовов, бронирований и продуктовой интеграции не было; код других экспериментов и официальный API-контракт не менялись.
