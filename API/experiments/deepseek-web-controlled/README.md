# TripFlow · Веб-подбор с лимитами

Открой [start-stand.cmd](start-stand.cmd) или запусти `python -X utf8 stand.py` из этой папки. Стенд открывается на [127.0.0.1:8768](http://127.0.0.1:8768/). Нужны Python 3.11+ и `DEEPSEEK_API_KEY` в локальном `.env`. Git игнорирует ключ и папку `runs/`. Параметр `--no-browser` запускает только сервер.

## Подбор и карточки

Flash разбирает пожелания и предлагает поисковые фразы. Python выполняет запросы через отдельные DeepSeek Search и Fetch API. Он удаляет дубли ссылок, извлекает короткие выдержки и загружает выбранные страницы, когда первичной выдачи мало для карточки. Flash формирует JSON с короткими выдержками, по которым Python проверяет происхождение полей. Карточки сохраняют адрес, часы, координаты, фото, ссылки и цену, когда удалось найти данные. В раскрывающемся разделе можно показать до шести дополнительных сведений, подходящих к пожеланиям и источникам. [Документация Search & Fetch](https://api-docs.deepseek.com/guides/search/)

После первичной выдачи Python может уточнить гостиничный тариф и найти цены похожих отелей. Flash оценивает один отдельный номер за ночь и даёт диапазон. Приоритет имеют опубликованный тариф отеля и сопоставимые ставки. При отсутствии подходящих цен Flash даёт грубую оценку, которую интерфейс так и помечает. Тариф для нескольких гостей обозначается отдельно и используется как ориентир на номер. При сбое Flash стенд использует найденные ставки или показывает резервный ориентир, рассчитанный из бюджета поездки.

**Для проживания Python умножает цену одного номера на число ночей и путешественников.** Диапазон умножается так же. В расчёте учитывается один отдельный номер на каждого человека. Стоимость служит для планирования поездки. Наличие номеров на заданные даты стенд не проверяет.

## Учёт расходов

На одну подборку отелей и мест Python допускает до 7 попыток поиска, 5 загрузок страниц и 6 запросов к Flash. У запросов к модели есть совместный лимит 140 000 байт для тел запросов и 13 200 токенов по заданным пределам вывода. Бюджет выбранной поездки рассчитывается отдельно и использует уже собранные цены. Интерфейс показывает стоимость по пиковому тарифу в юанях, поиски, загрузки и фактический расход токенов. Это расчёт по расходу, который вернул DeepSeek. [Тарифы DeepSeek в юанях](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

Локальные проверки запускаются командой `python -X utf8 -m unittest -v`.

## Контрольный прогон

В браузере проверена поездка в Киото на семь ночей для четырёх человек с бюджетом 500 000 ₽. Поиск занял 31,5 с и вернул три отеля и три места. За поиск учтено 6 платных запросов, 2 платные загрузки и 39 897 токенов Flash. Расчётная стоимость по пиковому тарифу составила ¥0,15755. После выбора отдельный расчёт бюджета стоил ¥0,00625. Во всех оценках отелей стоимость номера за ночь умножалась на 28. Среди карточек остались отдельные пробелы в данных источников, включая адрес одной достопримечательности.
