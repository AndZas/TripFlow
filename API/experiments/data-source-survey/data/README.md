# Малые примеры живых ответов

`samples/<UTC-run-id>/` содержит только примеры, полученные живыми запросами. В каждом файле есть `evidence=live_response` и время; исходные значения ограничены первыми двумя объектами, поля контактов отфильтрованы. В раннем запуске A `retrieved_at` — начало запуска; в более поздних — завершение конкретного ответа. Это не сырые полные выгрузки.
