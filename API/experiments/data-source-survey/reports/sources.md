# Официальные источники и дата проверки

Проверено **15.10.2026 (Europe/Moscow)**. Это дата исследования, не гарантия сохранения тарифов. Ссылки ведут к первичным источникам. Числа в comparison.md относятся к доступным на эту дату страницам; неизвестная цена не считается нулевой. Аккаунты не создавались, условия через формы не принимались.
