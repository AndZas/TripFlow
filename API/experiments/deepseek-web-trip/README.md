# TripFlow · Веб-подбор поездки

[Отчёт о прогонах, расходах и ограничениях](report.md).

Открой [start-stand.cmd](start-stand.cmd) или запусти `python -X utf8 stand.py` из этой папки. Стенд откроется на [127.0.0.1:8767](http://127.0.0.1:8767/). Для нового поиска введи любое направление, даты, размер группы, общий бюджет в рублях и пожелания. Кнопка «Заполнить пример» подставляет поездку в Петербург. Затем выбери один отель и нужные достопримечательности и нажми «Посчитать бюджет».

Нужен Python 3.11+ и ключ `DEEPSEEK_API_KEY` в локальном `.env`. Сторонние Python-пакеты не требуются. Для запуска без браузера используй `stand.py --no-browser`, для другого порта добавь `--port 8768`. Остановка по `Ctrl+C` в консоли.

## Как работает эксперимент

- Flash получает всю карточку и параллельно исследует отели и достопримечательности через `deepseek_web_search`. Python загружает страницы из результатов через DeepSeek Fetch. Второй запрос к Flash извлекает JSON из выдержек, а Python сверяет цитаты с исходным текстом. В каждой группе показывается до трёх вариантов. Консоль показывает время, идентификаторы ответов и расход API. [Документация DeepSeek](https://api-docs.deepseek.com/guides/web_tools/) · [Search & Fetch](https://api-docs.deepseek.com/guides/search/)
- Карточка содержит название, описание, сведения о соответствии пожеланиям и ссылки на источники. Цена, адрес, часы, координаты и фото показываются при наличии данных. Фото ищется на открытой странице объекта, в её метаданных и в Wikimedia Commons по названию. Изображение либо его заглушка открывает карту по координатам, а при их отсутствии — поиск по названию и адресу.
- Бюджет суммирует найденные тарифы и оценки Flash на питание, городской транспорт, прочее и резерв. Ставка за номер в сутки пересчитывается из расчёта двух путешественников на номер, а билет на человека умножается на размер группы. Цена «от» учитывается как нижняя граница. Для иностранных валют применяется последний доступный курс Банка России с указанием даты. Отсутствие цены или курса делает итог неполным. [Курсы Банка России](https://www.cbr.ru/development/SXML/)

Поля карточки отправляются в DeepSeek. Подборки хранятся в памяти до перезапуска стенда. `.env` и `runs/` игнорируются Git.
