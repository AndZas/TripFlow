# Исследования TripFlow

В `API/` собраны исследования внешних источников и локальные стенды. Описанные ниже прогоны относятся к экспериментам. Развёрнутый FastAPI использует тестовый каталог и отдельный контракт. [Контракт Python API](CONTRACT.md) · [Кабинет на Render](PORTAL.md)

## Модель и стенды карточки

Для основной интеграции рассматривается прямой вызов DeepSeek с сервера Python. LM Studio остаётся дополнительным режимом для разработки и локальных прогонов. Модель помогает интерпретировать свободные пожелания, подбирать и проверять реальные варианты и оценивать расходы. Способ поиска и источники цен ещё выбираются.

- [Стенд DeepSeek Flash с поставщиками](research/deepseek-flash/README.md) сочетает модель с Russhotels, Geoapify и ставками Росстата.
- [Стенд веб-подбора через DeepSeek](research/deepseek-web-trip/README.md) ищет отели и достопримечательности в открытом вебе. [Отчёт о двух экспериментах](research/deepseek-web-trip/report.md) содержит результаты, ограничения данных и фактический расход на один подбор.
- [Первый стенд карточки и отчёт по LM Studio](research/card-preferences/REPORT.md) сохраняют результаты локального эксперимента.

## Что показал эксперимент

- **Geoapify Places** — наиболее полезный из проверенных источников для каталога музеев, исторических мест, природы, ресторанов и объектов размещения. В выборке из 100 объектов координаты и адресная строка присутствовали у всех; сайты — у 27%, фотографии — у 3%, описания — у 3%. Числовых цен и доступности гостиничных номеров не было.
- **GeoNames** подходит для поиска города и справочных сведений о стране, валюте и часовом поясе. **Open-Meteo Geocoding** проверен как альтернатива для поиска города и координат.
- **CLDR** можно использовать как локальный справочник валют. **Frankfurter v2** пригоден для справочного обменного курса, когда он нужен; это не курс конкретного бронирования.
- Бесплатный каталог объектов не решает задачу реальных цен и наличия гостиниц. Для этого потребуется отдельный источник предложений либо отдельная, явно помеченная оценка с известным основанием.

Это выводы небольших исследовательских запусков, а не окончательные архитектурные решения. Масштаб, условия использования источников и продуктовые требования нужно учитывать при дальнейшем проектировании.

## Материалы эксперимента

В [`experiments/data-source-survey/`](research/data-source-survey/README.md) находятся:

- скрипты для основного и расширенного запусков;
- протокол и первоначальная задача исследования;
- отчёты сравнения, полей API, источников и проверок;
- датированные JSON-результаты запросов и небольшие очищенные примеры;
- локальный калькулятор оценки проживания, который не подставляет неизвестную цену.

В [`experiments/free-api-gap-test/`](research/free-api-gap-test/README.md) находится дополнительная проверка Geoapify Geocoding, OpenTripMap, TRY/RUB у Frankfurter и условного этапа Wikidata/Commons. Её [оценка](../experiments/free-api-gap-test/reports/assessment.md) содержит актуальные выводы и ограничения; [официальные тарифы и документация](research/free-api-gap-test/reports/sources.md) собраны отдельно. Запуск, требующий API-ключей, выполняется только по явному флагу `--live`.

Расширенный этап включал **45 живых API-запросов**: 40 в полном прогоне и 5 в отдельной проверке идентичности объектов между поиском и Details. В отчёте проверки кода зафиксировано **40 автоматических тестов, OK**. Параметры и ограничения каждого запуска описаны в его папке `reports/runs/`.

## Повторный запуск

Для запуска без ключей достаточно открыть папку эксперимента и выполнить команду:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe run_survey.py --no-keys
```

Для расширенного сценария и настройки ключей используйте инструкцию [README эксперимента](research/data-source-survey/README.md) и [EXTENDED.md](research/data-source-survey/EXTENDED.md). Локальный `.env` и виртуальные окружения исключены из Git; пример переменных хранится в `.env.example`.
