# Внешние API и источники данных TripFlow

Состояние на 29.10.2026. Основной стек для MVP с поездками по России выбран по результатам экспериментов. Он включает источники объектов, бюджетных ставок и справочных сведений. Проверки выполнены в исследовательских скриптах; подключение всего стека к сервису ещё предстоит.

## Основной стек

### Объекты и бюджетная основа

| API / источник | Полезные данные и использование | Подтверждение |
|---|---|---|
| **Geoapify Places / Place Details** | Реальные достопримечательности, категории, координаты, адреса, сайты; описания, часы работы и изображения при наличии. Также резервный каталог отелей. Details запрашивается при необходимости дополнительных сведений. | Ключ использован в живых проверках. В выборке 100 объектов координаты и адресная строка были у всех, название — у 91; цены и наличие номеров не получены. |
| **Russhotels / «Сусанин» API** | Российские отели, описания, координаты, варианты размещения и опубликованные тарифы. Основной источник гостиничных кандидатов и возможных ценовых ориентиров. | Публичный поиск проверен без авторизации. В первой выборке по шести городам получены 18 отелей с положительными тарифами. Свежесть, единица цены и соответствие размещению проверяются отдельно; наличие на даты не подтверждено. |
| **Росстат, открытые выгрузки** | Средние ставки проживания, питания, городского транспорта и посещений по территориям. Основа общих бюджетных оценок, включая резерв при отсутствии цены конкретного объекта. | Выгрузка за сентябрь 2026 года сохранена в локальный JSON. Данные читаются без сетевого запроса при каждой генерации. Это статистика города/региона, а не цена выбранного отеля или билета. |

Для поддерживаемых направлений стремимся обеспечить полную или близкую к полной бюджетную основу и пригодные данные реальных объектов. Покрытие проверяем при добавлении направления: успешные малые выборки не гарантируют полноту по всей России. Пригодная основа обязательных расходов необходима для успешного расчёта; конкретные рекомендации могут отсутствовать согласно [контракту](CONTRACT.md).

### Справочные сведения и наполнение карточек

Эти источники также входят в основной стек, но не требуют вызова при каждой генерации. Неполнота необязательных сведений допустима.

| API / источник | Полезные данные и использование | Подтверждение / условие |
|---|---|---|
| **Geoapify Geocoding** | Поиск города, координаты, страна и регион для подготовки справочника направлений. | Проверен с ключом на четырёх городах. При неоднозначности требуется выбор правильного населённого пункта. |
| **GeoNames** | Географические сведения, часовой пояс, языки и валюта страны. Используется при подготовке справочников; не дублирует геокодирование автоматически. | Проверены поиск городов и справочные endpoints с личным username. Подтверждены четыре города и валюты RU/RUB, FR/EUR, TR/TRY. |
| **Unicode CLDR** | Локальный справочник валют стран. | Получены и проверены справочные данные; отдельный запрос на каждую поездку не нужен. |
| **Frankfurter v2** | Справочный курс для пересчёта известной суммы в рубли. | Живыми запросами проверены EUR/RUB и TRY/RUB. Ключ не требуется; для сумм в RUB запрос пропускается. |
| **Wikidata / Wikimedia Commons** | Выборочные описания и фотографии существующих объектов. Необязательное обогащение после точного сопоставления. | Проверены публичные запросы: два из трёх выбранных QID дали подтверждённое соответствие и фото. Использование изображения зависит от его лицензии; проверенные CC BY-SA-фото требуют атрибуции и не подходят для показа только URL без неё. |

Географию готовим заранее в справочниках; Python получает выбранное направление от backend. Изображения, описания, сайты и прочие необязательные сведения возвращаются при наличии. Неизвестная цена остаётся `null`, а общая статистическая оценка хранится отдельно от цены объекта.

## Варианты для дальнейшего рассмотрения

К этим источникам возвращаемся после запуска основного стека.

| API | Возможная польза |
|---|---|
| **KudaGo** | Российские места, описания, изображения и сведения о событиях. Сохранённые пробы завершились разрывами соединения. |
| **OpenTripMap** | Дополнительный каталог достопримечательностей с описаниями и изображениями. Проверен с ключом, но обогащение тех же объектов Geoapify не подтверждено. |
| **Open-Meteo Geocoding** | Запасной поиск городов, координат и часового пояса; проверен без ключа. |
| **OpenStreetMap / Overpass** | Запасной прямой поиск объектов OSM; в экспериментах были успешные ответы и повторяющиеся сбои. |
| **DATAtourisme** | Каталог мест и отелей Франции с описаниями. Ключ получен, полезные данные подтверждены; потребуется при расширении географии. |

API нейросети выбирается отдельно. Модель будет обрабатывать предпочтения, ранжировать реальные варианты и участвовать в оценке расходов на основе исходных данных; конкретный поставщик пока не выбран.
