# TripFlow — локальная демонстрация внешних источников

Требуется Python 3.11 или новее, дополнительные пакеты не нужны.

Из корня репозитория:

```powershell
python API/demo/server.py
```

Открыть **http://127.0.0.1:8765**. Другой порт: `python API/demo/server.py --port 8766`. Остановка — `Ctrl+C`.

Ввести российский город и выбрать подсказку либо нажать один из примеров. Отображаются реальные отели Russhotels, достопримечательности Geoapify, метаданные GeoNames и локальные ставки Росстата. У каждого источника показан результат обращения; ошибка одного не скрывает остальные данные. Структурированный ответ доступен внизу страницы.

## Настройка

- `GEOAPIFY_API_KEY` — ключ Geoapify для поиска достопримечательностей.
- `GEONAMES_USERNAME` — логин с включёнными Free Web Services для поиска городов и метаданных. Без него поиск городов использует Geoapify.

Настройки читаются из окружения процесса, а в Windows также из пользовательских и системных переменных. Переменные, добавленные после запуска сервера, требуют перезапуска сервера. Ключи не передаются в браузер и не записываются в журнал запросов.

## Границы демо

- Сервер слушает только `127.0.0.1`. Это исследовательское демо, отдельно от frontend команды и будущего контракта Python API.
- Результат по городу кешируется в памяти на 10 минут, в том числе статусы источников. Для немедленной повторной проверки перезапустить сервер.
- Названия городов разрешаются через внешний геокодер. Это шире текущего продуктового справочника; наличие города в подсказках не гарантирует покрытие всех источников.
- Ставки Росстата — сохранённые данные за сентябрь 2026 года, а не новая загрузка с сайта. Резерв: город → регион при точном совпадении названия → страна; область видна для каждой ставки.
- Тарифы отелей показываются как исходные ориентиры поставщика; свежесть, единица и наличие на даты не подтверждаются. В бюджет цены автоматически не пересчитываются.
- Нейросеть, бронирование, авторизация и генерация карточки по контракту в это демо не входят.
- Фото не подставляются, если нет проверенного подходящего источника. Геоданные Geoapify основаны на OpenStreetMap, географические сведения — GeoNames; ссылки на карту ведут в OpenStreetMap.

Источники: [GeoNames](https://www.geonames.org/), [Geoapify](https://www.geoapify.com/), [OpenStreetMap](https://www.openstreetmap.org/copyright), [Russhotels](https://russhotels.ru/), [Росстат](https://rosstat.gov.ru/statistics/price).
