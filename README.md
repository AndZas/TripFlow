# TripFlow
  TripFlow - веб-сервис предназначен для совместного планирования путешествий
группой пользователей. Участники смогут создавать поездки, предлагать
направления и места для посещения, голосовать за варианты, формировать
маршрут и учитывать предполагаемые расходы.
В систему будет встроен интеллектуальный модуль, который на основе
параметров поездки будет рассчитывать примерную стоимость
путешествия, а также предлагать альтернативные варианты направлений с
учётом голосования участников, бюджета и других предпочтений.
